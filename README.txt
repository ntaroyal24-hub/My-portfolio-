ROYAL GODSWISDOM NTA — PERSONAL PORTFOLIO
=========================================

FILES
- index.html       Main portfolio / advertising page
- article.html     Personal article page
- style.css        Shared responsive styling and futuristic typography
- script.js        Small mobile navigation toggle
- images/royal-portrait.png   Suit-and-tie portrait for the portfolio
- images/royal-mic.jpg        Microphone photo for the article hero

HOW TO USE
1. Extract the ZIP folder.
2. Open the extracted folder in Acode, SPCK Editor, or another code editor.
3. Open index.html in your browser to view the portfolio.
4. The "Read My Story" links open article.html. The article page links back to index.html.

NOTES
- The design uses a dark navy, electric blue, and cyan palette.
- It uses HTML, CSS, and a small amount of beginner-friendly JavaScript.
- Google Fonts (Orbitron and Rajdhani) load when internet is available; fallback fonts are included.
- No build tools or frameworks are required.
